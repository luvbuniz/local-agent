# Insights: how to add an article

Pages here are plain static HTML generated by `insights/_tools/build.py`. Folders starting with `_` are not published by GitHub Pages (Jekyll skips them).

**Only publish an article after Amy approves it.**

1. Copy `insights/_template/article-template.md` to `insights/_posts/<slug>.md` and fill in the front matter. Keep `draft: true` until Amy approves.
2. Put images in `insights/images/`:
   - cover: `<slug>-cover.jpg`, 1200x675 JPEG (used on the page and for OG/Twitter)
   - thumbnail: `<slug>-cover-thumb.jpg`, 480x270 (used on the /insights/ listing)
   - inline images: max 1200px wide, JPEG for photos, PNG for diagrams
   Example: `python3 -c "from PIL import Image; im=Image.open('in.png').convert('RGB'); im.resize((1200,675)).save('insights/images/<slug>-cover.jpg',quality=82); im.resize((480,270)).save('insights/images/<slug>-cover-thumb.jpg',quality=80)"`
3. Once approved, delete the `draft: true` line and run `python3 insights/_tools/build.py` (needs `pip install markdown`).
   It writes `insights/<slug>/index.html`, rebuilds `insights/index.html` (newest first), and refreshes the Insights block in `sitemap.xml`.
4. Commit and push to the Pages branch (`claude/push-request-1jkwzu`), then request indexing for the new URL in Google Search Console.

To edit a published article, edit its `.md` file, optionally add `updated: YYYY-MM-DD`, and rerun the build. Edit the shared header/footer in `insights/_template/header.html` / `footer.html`; if you change the main nav, also update `index.html` and `intake/index.html`.
